# Changelog

## 0.1.2 — Content Editor UI refresh
- Redesain header, tab, panel daftar, form, tombol, dan tabel agar lebih rapi dan terbaca.
- Memperbaiki panel daftar bahan/resep yang sebelumnya tidak dipasang ke layout sehingga tampil kosong.
- Memperbesar ukuran awal jendela dan mengatur lebar awal panel daftar.
- Tidak mengubah format JSON atau perilaku penyimpanan data.

## 0.1.3 — Recipe editor fix
- Memperbaiki panel daftar resep yang dapat terlipat/mengecil akibat sash `Panedwindow`; diganti dengan grid dua kolom yang stabil.
- Mengganti dialog penambahan bahan dengan builder inline: pilih bahan, jumlah, dan timing langsung pada tab Resep.
- Menyatukan aksi tambah, perbarui, hapus, dan ubah urutan di dekat tabel langkah.
- Memastikan tombol Simpan resep dan Bersihkan form tetap terlihat di bagian bawah.
- Memadatkan detail resep agar builder tetap dapat digunakan pada resolusi desktop 1280 × 720 atau lebih besar.
- Tidak mengubah format JSON resep maupun bahan. Tab Bahan Makanan tidak diubah.
