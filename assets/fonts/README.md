# Font Cooking TXT

Tambahkan tiga file font berikut ke folder ini untuk mengaktifkan tipografi tema:

- `Fraunces-SemiBold.ttf`
- `NunitoSans-Regular.ttf`
- `NunitoSans-Bold.ttf`

Unduh keluarga font Fraunces dan Nunito Sans dari Google Fonts. Periksa lisensi dan ketentuan distribusi sebelum memasukkan file font ke repository publik. Game masih bisa berjalan tanpa font tersebut, tetapi akan memakai fallback Pygame.
